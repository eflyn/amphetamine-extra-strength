# Changelog

All notable changes to Amphetamine Extra Strength are documented here.

## [1.1.0] - 2026-08-01

First public release.

### Added

- Automatic dimming and restoration of the built-in display when the MacBook
  lid and configured Amphetamine conditions are satisfied.
- Independent dimming and restoration of the built-in keyboard backlight.
- Manual-override detection, crash recovery, and restore retries.
- Optional read-only Amphetamine session checking and launch-at-login support.
- Universal Apple Silicon and Intel release packaging.
