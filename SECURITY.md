# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
[GitHub's private vulnerability reporting](https://github.com/eflyn/amphetamine-extra-strength/security/advisories/new)
and include the affected macOS version, app version, reproduction steps, and
expected impact. Release timing depends on severity, reproducibility, and the
availability of a safe fix.

## Supported versions

Security fixes are made against the latest release. Users should update to the
latest available version before reporting an issue.
